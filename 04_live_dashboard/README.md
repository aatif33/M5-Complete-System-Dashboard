# 04 — Live dashboard

The included `dashboard_prototype.html` is a static front-end concept with sample placeholders. It is not connected to a camera, detector, MQTT broker, PLC or motor alert.

For the final assessment, connect live data and show:
- Camera feed
- PASS / FAIL decision
- Live detections
- At least three KPIs (e.g. throughput, pass rate, latency)
- Motor/anomaly alert
- Timestamp and connection status
