# 01 — Inspection rig

Assessment proof: fixed, repeatable camera and lighting rig, plus an image set containing every defect type.

Record:
- Camera model, lens, height, angle and focus.
- Light source, position, brightness and ambient conditions.
- Part position/orientation and fixture dimensions.
- Defect taxonomy and representative image per defect type.
- Repeatability check after removing and replacing a part.

Attach original photographs and a rig drawing. The rig must be reproducible by another person.
