# 02 — Pass/fail station

Assessment test: 20 parts total (10 good, 10 defective). Record ground truth and prediction for every part. Report confusion matrix and false-pass rate.

A false pass is a defective part predicted as PASS. Calculate:
false-pass rate = false passes / number of defective parts × 100%.

Do not infer a result from a demo UI. Complete the test log using actual physical parts and preserve the per-part evidence.
