# M5 — Complete System + Dashboard

**Project context:** Raspberry Pi 5 carton seal inspection (SEALED / OPEN), with OLED enclosure camera setup as a separate M1 workstream.  
**Package type:** integration plan, dashboard prototype, test templates and demo assets. Not proof of a completed physical inspection station.

## Eight M5 assessment criteria
1. Inspection rig
2. Pass/fail station
3. Full chain on the device
4. Live dashboard
5. Product readiness
6. Headline metric
7. Documents
8. Live demo and questions

## Suggested workflow
1. Document and photograph a fixed camera/light/target rig.
2. Test 20 physical parts: 10 good and 10 defective.
3. Integrate camera → model → decision → output → dashboard on the target device.
4. Run the complete system continuously for 10 minutes and record failures.
5. Verify auto-start after power-cycle, offline operation and persistent logs.
6. Calculate one headline metric from the 20-part test (or a larger documented sample).
7. Commit README, datasheet, architecture and demo video.
8. Rehearse one normal run and one injected fault.

## Evidence integrity
The included dashboard and test templates are prototypes. No physical part test, 10-minute run, power-cycle, offline test or headline accuracy result is claimed as completed.
